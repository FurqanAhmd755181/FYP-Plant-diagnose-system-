🌱 Plant Diagnose System
A smart plant disease diagnosis mobile application that helps users identify plant diseases using images and provides detailed disease information, care tips, and health monitoring insights.
The system is built with a React Native frontend and a Python-based backend, designed to support farmers, gardeners, and agriculture enthusiasts.

🧠 Overview
The Plant Diagnose System is an intelligent agriculture application that allows users to upload or capture images of plants to detect diseases using machine learning models.
The app provides: - Disease prediction results - Disease descriptions and causes - Recommended treatments and prevention tips - Plant health monitoring support
This project demonstrates real-world use of AI in agriculture, mobile app development, and API-driven architecture.

⚙ Installation & Setup
1️⃣ Clone the repository
git clone https://github.com/your-username/plant-diagnose-system.git
cd plant-diagnose-system
________________________________________
2️⃣ Mobile App Setup
cd mobile-app
npm install
npm start
________________________________________
3️⃣ Backend Setup
cd backend
pip install -r requirements.txt
python app.py
________________________________________
🔐 Environment Variables
Create a .env file in the backend directory:
FLASK_ENV=development
MODEL_PATH=path_to_trained_model
SECRET_KEY=your_secret_key
________________________________________
▶ Run the Project
•	Start the Flask backend
•	Run the React Native app using Expo or emulator
•	Connect the app with backend APIs
